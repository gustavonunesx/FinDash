# FinDash 2.0 — Design System

## Color Strategy
Restrained (light) / Committed (dark): teal como único acento, tudo mais neutro.

## Tokens

### Light mode (QPay)
- Background: #F5F7F7
- Card: #FFFFFF
- Primary/Teal: #00BFBF
- Heading: #1A3A3A
- Secondary text: #6B8888
- Border: #E0EEEE
- Shadow: 0 1px 4px rgba(0,140,130,0.06), 0 4px 16px rgba(0,0,0,0.04)

### Dark mode (FinDash original)
- Background: #0F0F13
- Card: #1A1A24
- Primary: #1D9E75
- Foreground: #F0F0F5
- Border: #2A2A38

### Category tokens (ambos os modos)
- fd-green: gastos tipo "objetivo" / positivo
- fd-amber: gastos tipo "necessidade" / atenção (#E8923A no light)
- fd-blue: info / custódia
- fd-red: perigo / excedido
- fd-purple: premium

## Typography
- Body/UI: DM Sans (novo) com fallback Plus Jakarta Sans
- Números/código: JetBrains Mono
- Escala: 10px metadata / 12px body / 14px card title / 16px section / 20px heading / 28–32px metric

## Spacing
Escala 4pt: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64

## Border Radius
- Badges/pills: 9999px
- Botões/inputs: 8px
- Cards pequenos: 10px
- Cards grandes: 14px
- Hero banners: 16px

## Elevation
- Card padrão: border + shadow sutil
- Modal: shadow-premium
- Sem sombras exageradas no light mode
